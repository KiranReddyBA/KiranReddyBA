## 📌 Pinned Projects

### 1. 🤖 Enterprise AI Chatbot with RAG Pipeline
> Built an enterprise AI chatbot using **LangChain**, **OpenAI GPT-4**, and **FastAPI** that connects to PostgreSQL databases, enabling natural language queries across structured enterprise data.

- Implemented **RAG pipeline** using FAISS vector database and sentence embeddings
- **Tool-calling agent** for autonomous SQL query execution and API data retrieval
- Deployed on **AWS (EC2, Lambda)** with Docker — 99.9% uptime, 10K+ daily queries
- [🔗 Live Demo & Source Code](https://github.com/KiranReddyBA/enterprise-ai-chatbot)

### 2. 📊 Customer Churn Prediction
> End-to-end ML pipeline on 500K+ records using **Random Forest** and **XGBoost** — 91% accuracy.

- Feature engineering with SHAP for model interpretability
- Deployed as **REST API** using FastAPI for real-time churn risk scoring

### 3. 🧠 Multi-Agent AI System for Data Analysis
> Multi-agent system using **CrewAI** and **LangGraph** that autonomously analyzes datasets and generates reports.

- Specialized agents: data analyst, SQL writer, report generator
- Integrated with **OpenAI API** and **PostgreSQL**
